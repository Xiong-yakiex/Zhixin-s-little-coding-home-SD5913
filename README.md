The needs of artist to learn Programming

Nowadays, computers have become an essential form of new media. Almost everything we want to create or achieve in the digital world requires the help of computers. For people without programming knowledge, it can be difficult to fully use these technologies or turn their ideas into reality. Therefore, having basic programming skills can make the creative process easier and provide more possibilities for future development.

For me, during my undergraduate studies, I took a Unity game development course because of my interest in games. Unity was enjoyable, but programming quickly became frustrating. I could not write code independently, so I often relied on artificial intelligence or online searches to find solutions. I copied code that could achieve the functions I wanted, but I rarely understood how or why it worked. When errors appeared, I often did not know how to fix them. Therefore, I was given up on programming.

However, after the first week of this course, my perspective changed. I realized that programmers do not always know the solution immediately. Programming is often a process of identifying a problem, searching for information, testing possible solutions, and correcting errors. Therefore, I believe that learning how to solve programming problems in a right way is more valuable than simply memorizing code and that is the main reason why I am seating in this class room.

For art and design students, the first important thing needs to learn is computational thinking. Wing (2006) describes computational thinking as an approach to problem-solving based on concepts from computer science. Designers can use this thinking to divide a complex creative idea into smaller tasks and translate visual concepts into logical processes. Romero et al. (2017) also suggest that creative programming can develop computational thinking through problem-solving and creative activities.

Programming can also become a creative medium. Amiri (2011) argues that programming in art and design education should be considered a form of design practice rather than only a technical skill. Through programming, designers can create interactive experiences, generative artworks, games, and digital products. Li et al. (2023) further found that art programming education can support both computational thinking and design thinking among art and design students.

My previous experience with Unity therefore represents an important lesson. Instead of asking AI or search engines for code and copying it directly, I need to learn how to identify the problem, understand error messages, search with appropriate keywords, evaluate information, and test solutions. AI can assist this process, but understanding the logic remains essential.

In conclusion, though art and design students do not need to become professional programmers. However, they should develop basic programming knowledge, computational thinking, debugging skills, and the ability to find and evaluate technical information. For me, the most valuable outcome of learning programming is not being able to memorize more code, but knowing how to learn when I do not know the answer.
